# Marinara CR Close

Read the [shared contract](../marinara-change-request/SHARED_CONTRACT.md). Use this stage only after an authorized completion, integration, supersession, or archive decision.

Update `change_requests/tracker.md` for local-main integration, PR opening/merge, supersession, or archive. For archival, move the CR folder to `change_requests/archive/CRXXX_short_title/` and record the archived state and relevant notes. Do not continue active work from archived folders, and do not claim validation the user did not perform.

Exit with the exact tracker state, artifact location, and remaining follow-up or authority requirement.
